📖 Project Overview

JourneyQuest is a comprehensive travel guide web application built using Flask and SQLite. It allows users to explore destinations by travel themes, view detailed travel information, and discover hotels, restaurants, and attractions—all through an intuitive and responsive interface.

  • 🗺️ Explore destinations by travel tags (Adventure, Beaches, History, etc.)
  • 🏙️ City-wise detailed travel data (Hotels, Restaurants, Attractions)
  • ⚙️ Dynamic backend with Flask & SQLite
  • 📱 Fully responsive UI using Tailwind CSS

🚀 Running the Project

Follow these steps to run JourneyQuest locally and explore the travel guide in action.

  • Fork and clone the repository from GitHub.
  • Install dependencies using pip install -r requirements.txt.
  • Run python app.py to start the Flask server.
  • Visit http://127.0.0.1:5000 in your browser.
