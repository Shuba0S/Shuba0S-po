# 💻 Shuba S - Portfolio

## 📖 Introduction

This is my **personal portfolio website** built using **FastAPI**, **HTML (Jinja2)**, and **Tailwind CSS**.
It showcases my work, skills, and services as a **Python and Full Stack Developer**.
The portfolio highlights my projects, technical expertise, and provides easy access for collaboration or contact.

---

## 🔗 Live Demo

Check out the deployed portfolio here: [Shuba S - Portfolio](https://shuba-s.vercel.app/)

---

## 🎯 Purpose

The goal of this portfolio is to:

* Present my **skills, projects, and professional journey** in a clean, modern layout.
* Offer a **central hub** for recruiters, clients, or collaborators to learn about my work.
* Showcase my focus areas in **Python Development**, **Full Stack Web Development**, **Game Development**, and **MERN Stack Development**.
* Provide a way to **contact me directly** for professional opportunities.

## 🛠️ Tech Stack

### ⚙️ Backend

* **FastAPI** – For serving pages and managing backend routing.
* **Jinja2** – Template engine for rendering HTML dynamically.

### 🎨 Frontend

* **HTML5 / CSS3 (TailwindCSS)** – For clean and responsive UI design.
* **Custom Manual CSS** – Used for fine-tuned animations and styling details.

### 🗄️ Other Tools

* **Python 3.10+** – Core language for backend logic.
* **Uvicorn** – ASGI server for running FastAPI efficiently.
* **Git & GitHub** – Version control and project management.

## 🚀 Running the Project

### 1️⃣ Fork the Repository  
   Click the **Fork** button at the top-right of this repository to create your own copy.  

### 2️⃣ Fork the Repository  
   ```bash
   git clone https://github.com/your-username/Blood-Bank-MS.git
   cd Blood-Bank-MS
   ```

### 3️⃣ Create and Activate Virtual Environment

```bash
python -m venv venv
source venv/bin/activate       # On macOS/Linux
venv\Scripts\activate          # On Windows
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Run the Application

```bash
uvicorn main:app --reload
```

### 6️⃣ Access in Browser

```
http://127.0.0.1:8000/
```
